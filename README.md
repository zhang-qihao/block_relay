# 方块来袭 · Block Relay

局域网多人俄罗斯方块：消行互攻、实时查看所有玩家棋盘，也能一起合作守城。

## 安装

需要 Node.js 20 或更新版本。

```bash
git clone https://github.com/zhang-qihao/block_relay.git
```

```bash
cd block_relay
```

```bash
npm install
```

## 启动

```bash
npm start
```

- 本机打开 **http://localhost:3000**。
- 其他玩家连接同一 Wi-Fi／局域网，打开终端显示的**局域网地址**，不要使用 localhost。
- 在房间码与“加入”之间点击 **“查找”**，弹出当前服务器房间列表；可按房间码或房主搜索，选择加入。对战中或满员的房间仅显示状态。
- **机器人**：房主可在准备房间的玩家列表上方选择简单、普通或困难机器人并添加，计入 6 人上限。机器人自动准备，可用姓名旁的“踢出”移除；按正常动作参与对局、净化和炸弹传递，不进入真人排行榜。最后一名真人离开后房间自动清理。
- 一人创建房间，其他人输入房间码加入。房主选择玩法，所有人准备后开始。
- 首页排行榜可通过下拉框选择模式，各模式独立排名并展示前三名；同名仅合并该模式的最高分，无账号验证。服务器保存到 `data/leaderboard.json`，成功保存后重启和更新均保留，迁移服务器请备份该文件。旧成绩按原记录的模式归入对应榜单。
- 房间内左侧可聊天；最近 100 条记录跟随房间，加入、重连和再开均保留，房间销毁或服务重启后清除。手机可展开房间聊天，不遮操作盘。
- 保持服务运行；重启会清空房间。连接不到时，请检查系统防火墙及路由器的设备隔离设置。

需要更换端口时，设置 `PORT` 环境变量，例如 macOS／Linux：

```bash
PORT=3001 npm start
```

后台启动（macOS／Linux）：

```bash
bash app.sh start
```

停止或重启：

```bash
bash app.sh stop
```

```bash
bash app.sh restart
```

一键从 `origin/master` 快进更新、安装依赖、检查代码并重启：

```bash
bash update.sh
```

脚本将日志写入 `logs/app.log`，进程和端口记录在 `.run/`；可用 `PORT=3001 bash app.sh start` 指定端口，后续重启会沿用。首次使用前请停止之前通过 `npm start` 或 `nohup` 启动的服务，脚本不会接管或误杀其他进程。更新会清空对局；遇到未提交文件、分支分叉、依赖安装或检查失败时不执行重启，不强制覆盖本地代码。此脚本不提供开机自启，电脑休眠时无法继续提供服务。

## 玩法列表

| 玩法 | 怎么玩 | 人数 |
| --- | --- | --- |
| **好友乱斗** | 每次攻击随机选择一位存活对手，最后存活者获胜。默认推荐。 | 2–6 人 |
| **三分钟挑战** | 限时比消行，存活者优先，同消行再比分数。默认三分钟，可在选配规则中调整。 | 2–6 人 |
| **消行竞速** | 无玩家攻击；率先完成目标行数，或成为最后存活者。 | 2–6 人 |
| **团队对抗** | 红蓝两队人数相等，只攻击敌方，最后存活队伍获胜。 | 2／4／6 人 |
| **挖掘挑战** | 同样的障碍开局，先挖干净者获胜；无攻击、禁净化。 | 1–6 人 |
| **合作守城** | 一起抵御障碍波次，消行先自保，余量自动救援队友。末波后坚持 20 秒过关。 | 1–6 人 |
| **自由练习** | 没有攻击，自由练习操作，也能观看朋友的棋盘。 | 1–6 人 |

- **电脑**：方向键移动／旋转，空格硬降，C 暂存，V 净化。手动点名默认攻击房间顺序的前一位，首位选最后一位，也可点击棋盘更换目标。
- **手机**：底部拇指操作盘支持方向长按和同时旋转，硬降单独按键防误触；点击“切换手势”后，轻点本人棋盘旋转、横拖移动、下拖软降，硬降仍使用按钮。
- **炸弹反馈**：主棋盘与右侧玩家小棋盘均标记当前持有者并同步闪烁，不显示剩余秒数。传递不重置引信，接收者重新累计消行；爆炸覆盖目标棋盘并播放音效，遵守静音开关。爆炸后，新炸弹随机交给另一位存活玩家。
- **音效**：自己的消行与实际受击有短音效，首次点击或按键后解锁；右上角可静音。浏览器不支持或阻止音频时仍可正常游戏。
- **淘汰观战**：选择敲玻璃、番茄、彩纸、手印或烟花，点存活玩家的小棋盘，效果出现在对方对应位置并全房同步；每次有效点击立即触发，可连续点按，无互动冷却，不影响胜负。
所有推荐玩法的攻击方式默认设为 **随机攻击**；消行竞速、自由练习、挖掘挑战和合作守城均不攻击对手。炸弹传递仍按下一位存活玩家顺序，与消行攻击的随机目标互不影响。房主选择 **推荐玩法** 后，可选择 **攻击分配**，再点 **“选配规则”** 打开弹窗调整时长、目标和适用的攻防开关；修改即时同步，所有玩家需要重新准备。当前选配以标签显示在按钮下方，非房主只能查看。选配不改变玩法名称，更换玩法恢复默认配置。受击暂存区用横排展示待接收障碍，消行抵消时对应行变绿消失；普通障碍补齐缺口也能消除。

- **乱扔垃圾（选配）**：默认关闭，开启后每 30 秒向所有存活玩家增加 1 行环境障碍，不改变玩法胜利条件；可在选配规则中开关，房间标签显示当前状态。手动点名仅是攻击分配方式，不再单列推荐玩法。

- **烫手山芋（选配）**：默认关闭，可叠加到任意玩法；至少两位玩家存活时运行，持有者累计消 1 行后按 B 或点按钮传递，爆炸加 1 行，新炸弹随机交给另一位存活玩家。只剩一位存活玩家时停止生成炸弹，仍按原玩法判定胜负。
